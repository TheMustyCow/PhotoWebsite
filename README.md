# Photo Website

## Objective
- I created this project to learn how to use html, css, and javaScript; now I am modifying it into an application where a user can show people their photos.
- The goal is for this to be a local social media so that someone may show photos without it being something uploaded off the internet.
    - The main reason I wanted this, was for a more professional way to show people my photography without having to use Instagram.
